## About

Final-year computer engineering student at **ENSI** (Tunisia), working on cloud infrastructure, agentic AI and deep learning. Currently looking for an end-of-studies internship (**PFE**).

This repository holds my personal portfolio: a single-page site with scroll-driven animations, a physics-based 3D skills section and illustrated case studies of my projects.

## Site features

- **Hero** with a magnetic, cursor-following 3D avatar
- **Work strip** that scrolls with the page: code snippets, key figures and project diagrams
- **About** text revealed character by character as you scroll
- **Skills** as glass 3D balls with real physics: grab, throw and push them
- **Projects** as sticky cards that stack while scrolling

## Tech stack

`React 18` · `TypeScript` · `Vite` · `Tailwind CSS` · `Framer Motion` · `Three.js` · `React Three Fiber` · `Rapier physics` · `Simple Icons` · `Lucide`

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Deployment

Hosted on **Render** as a Static Site:

| Setting | Value |
|---|---|
| Build command | `npm ci && npm run build` |
| Publish directory | `dist` |
| Environment | `NODE_VERSION=20` |
