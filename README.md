# Sarra Bouraoui — Animated Portfolio

### 🌐 [sarrabouraoui.onrender.com](https://sarrabouraoui.onrender.com)

</div>

An animated portfolio website I built for my friend **Sarra Bouraoui**, a computer engineering student at **ENSI** (École Nationale des Sciences de l'Informatique, Tunisia) who works on cloud and AI.

The site presents her profile, skills and projects with motion throughout:

- a 3D avatar that follows the cursor
- a strip of her work that scrolls with the page
- text revealed letter by letter as you scroll
- skills shown as glass 3D balls you can grab and throw
- project cards that stack while scrolling

**Built with** React, TypeScript, Vite, Tailwind CSS, Framer Motion and Three.js (React Three Fiber + Rapier physics). Hosted on Render.

## Run locally

```bash
npm install
npm run dev
```
